# 브리핑 고지문

발행 템플릿은 이 문서의 세 고지를 `briefing.notices.safety`,
`briefing.notices.copyright`, `briefing.notices.investment`에 반영한다.
구조화 계약은 [`schemas/briefing.schema.json`](../schemas/briefing.schema.json)이며,
항목별 근거 계약은 [`schemas/briefing_item.schema.json`](../schemas/briefing_item.schema.json)이다.

## 안전 고지 (Safety Notice)

이 자료는 공개 자료를 바탕으로 한 리서치 요약이다. 외부 문서와 모델 출력은
신뢰되지 않은 데이터로 취급하며, 실제 적용 전 원문·문서 버전·근거 위치와
한계를 직접 확인해야 한다. 이 시스템은 주문을 실행하거나 자동매매를 수행하지
않으며, 수익 또는 성과를 보장하지 않는다.

## 저작권 고지 (Copyright Notice)

원문 전문을 재배포하지 않는다. 인용은 필요한 근거로 제한하고 출처 URL,
문서 버전, 라이선스와 이용약관을 함께 보존한다. 각 브리핑 항목은 Evidence를
통해 원문 버전으로 역추적할 수 있어야 하며, 인용은 항목당 최대 2개·각 300자
이내로 제한한다.

## 투자 고지 (Investment Notice)

이 브리핑은 투자 자문, 종목 추천, 매수·매도 신호 또는 투자 권유가 아니다.
전략 설명은 원문에 명시된 내용을 요약한 것이며, 실제 거래에 적용하기 전에는
별도의 법률·리스크·데이터 품질 검토와 검증이 필요하다.
